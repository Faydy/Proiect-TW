# 🐾 Luna Family – Website despre pisicile mele

Acesta este proiectul meu pentru cursul de **Tehnici Web**, un website dedicat pisicilor mele: Luna, Sara, Urecheatu, Fricosu și Hasoon.  
Proiectul este realizat **fără framework-uri**, folosind doar **HTML si CSS**, respectând cerințele pentru punctaj maxim.

## ✨ Funcționalități și cerințe îndeplinite

### 🔹 HTML & CSS
- Layout complet pe mai multe pagini:  
  `index.html`, `galerie.html`, `luna.html`, `sara.html`, `urecheatu.html`, `fricosu.html`, `hasoon.html`
- Meniu complet cu **dropdown** realizat exclusiv cu CSS
- Folosirea de **Flexbox** și **Grid**
- **Design Responsive** (desktop + mobile)
- Animații CSS (hover pe imagini, scale-in, scale-out)
- Opacitate + transformări la hover
- Folosirea pseudo-elementelor `::before` și `::after`
- Paletă de culori inspirată din blana pisicilor
- CSS modular:  
  - `style.css` (layout principal + nav + home)
  - `common.css` (stiluri partajate)
  - `pisici.css` (pagini individuale)
  - `galery.css` (galeria de poze)

## 📸 Conținutul fiecărei pagini

### 🏡 Acasă (`index.html`)
- Prezentare generală
- Logo + meniu principal
- Elemente animate
- Poze tematice cu pisicile

### 🐱 Pagini individuale
- `luna.html`
- `sara.html`
- `urecheatu.html`
- `fricosu.html`
- `hasoon.html`

Fiecare include:
- Poză principală
- Galerie mică secundară
- Un paragraf descriere realist

### 🖼️ Galerie (`galerie.html`)
- 400+ imagini aranjate automat în grid responsive
- Hover animations (zoom in/out)
- CSS performant pentru multe poze
